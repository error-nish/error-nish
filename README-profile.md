## Projects & Engineering Work

### 01 · 32-bit RV32I RISC-V CPU
**A modular single-cycle processor designed in Verilog**

Working through the core datapath and control logic of a 32-bit RISC-V processor.

- Program counter and instruction fetch
- Instruction decode and control unit
- Register file and immediate generator
- ALU and branch logic
- Instruction and data memory
- Testbench-based simulation and debugging

`Verilog` `RV32I` `RTL Design` `Vivado` `Icarus Verilog`

**Repository:** [Find my RISC-V work](https://github.com/error-nish?tab=repositories)

**C-based hardware implementation and optimization**

Exploring an HQC encoder implementation through the Vitis HLS workflow.

- C implementation and C simulation
- HLS project configuration
- Synthesis and hardware-oriented optimization exploration

`C` `Vitis HLS` `Hardware Acceleration`
